# بُعد (BUD): منصة وساطة تأمينية رقمية

منصة تغطي رحلة العميل كاملة، من طلب التأمين حتى ما بعد إصدار الوثيقة.

| المرحلة | ما تغطيه |
|---|---|
| **الطلب** | بوابة عميل لكل فروع التأمين (10 فروع، 33 منتجًا)، مع رفع المستندات ومتابعة الطلب برمز تحقق على الجوال |
| **الاكتتاب** | رسائل طلب التسعير لشركات التأمين من قوالب قابلة للتخصيص، مع مراجعتها واعتمادها قبل الإرسال |
| **العروض** | تسجيل العروض يدويًا، أو استخراجها من بريد الشركات بالذكاء الاصطناعي ثم مراجعتها، ومقارنتها واختيار العرض |
| **الإصدار** | الوثيقة، وجدولة الأقساط، وعمولة الوساطة من العرض المختار |
| **ما بعد البيع** | التجديدات، والتحصيل، والعمولات، والمطالبات ومستنداتها، وملف العميل، والتقارير |
| **الأتمتة** | رسائل واتساب و SMS، وتذكيرات التجديد والأقساط، وطلبات التجديد التلقائية، ومتابعة الشركات المتأخرة |
| **الأمان** | دخول الفريق بأدوار (مبيعات، اكتتاب، مدير)، وسجل تدقيق لكل عملية حساسة |

## التشغيل محليًا

```
pip install -e ".[dev]"
docker run -d --name bud-pg -e POSTGRES_PASSWORD=pg -e POSTGRES_DB=bud -p 5432:5432 postgres:16-alpine
export DATABASE_URL=postgresql+asyncpg://postgres:pg@localhost:5432/bud
alembic upgrade head
python -m app.cli seed-demo                                   # بيانات تجريبية
python -m app.cli create-manager --email you@example.com --name "اسمك"
uvicorn app.main:app --reload                                 # http://localhost:8000
python -m app.automation.worker                               # في نافذة ثانية
```

- **لوحة الفريق:** `/dashboard/login.html`
- **بوابة العميل:** `/dashboard/portal.html`
- **متابعة الطلب:** `/dashboard/track.html`

## هيكل المشروع

| المجلد | المحتوى |
|---|---|
| `app/insurance/` | النماذج، والكتالوج، ودورة حياة الطلب، والقوالب، والأقساط والعمولات، والمستندات، والبريد |
| `app/automation/` | الرسائل، والقواعد، والمهام المجدولة، والعامل، وقراءة ردود الشركات |
| `app/api/routes/` | الـ API: الطلبات والاكتتاب، ما بعد البيع، الأتمتة، الدخول، متابعة العميل |
| `app/static/dashboard/` | الواجهات |
| `alembic/versions/` | ترحيلات قاعدة البيانات |
| `deploy/` | حزمة الإنتاج وسكربتات النشر والنسخ الاحتياطي |
